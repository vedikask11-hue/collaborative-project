# collaborative-project



\# Collaborative GitHub Project



\## Project Description

This project demonstrates a collaborative GitHub workflow

using feature branches, Pull Requests, code reviews,

pre-commit hooks and GitHub Actions.



\## Project Objectives

\- Learn Git and GitHub collaboration.

\- Create and manage feature branches.

\- Understand Pull Requests and code reviews.

\- Configure a pre-commit hook.

\- Implement basic Continuous Integration using GitHub Actions.



\## Technologies Used

\- HTML

\- Git

\- GitHub

\- GitHub Actions

\- Bash



\## Team Members

\- Student 1: HTML development and CI configuration.

\- Student 2: Documentation and pre-commit hook configuration.



\## Project Files

\- index.html: Project homepage.

\- README.md: Project documentation.

\- .git/hooks/pre-commit: Local pre-commit hook.

\- .github/workflows/ci.yml: GitHub Actions workflow.



\## Conclusion

This project demonstrates how two students can

collaborate effectively using GitHub.
